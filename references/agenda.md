# Vibe Coding Workshop — Structure v2 (post-feedback)

**Target length:** 90 minutes or less (shortened after feedback)
**Status:** Draft structure — content per section to be refined later

---

## Flow overview

Intro → What is Vibe Coding → The Spectrum → Models & Capabilities → Why Now → Basic Software Architecture → Live Demo → Closing

---

## 1. Introduction (~5 min)

- Who I am: name, background, what I work with
- Quick framing of what the session will cover

## 2. What is Vibe Coding? (~5 min)

- Origin story: the tweet that coined "vibe coding" (Andrej Karpathy, Feb 2025 — quote the tweet directly on the slide)
- What the term means in practice: describing what you want, letting the AI write the code, "giving in to the vibes"

## 3. The Spectrum (~5 min)

- One axis: **Vibe Coding ←→ Agentic Engineering ←→ Software Engineering**
- Key framing: vibe coding is _coding_, but it is not _software engineering_ — agentic engineering sits in the middle
- Where this workshop sits: close to the vibe coding end — "a few inches to the right" — not yet at agentic engineering

## 4. Models & Capabilities (~10 min)

- **Quick explainer (single slide):** "You've heard about 'models' — what is a model, and why are there different ones?"
- **Timeline of models:** marking key releases and what each unlocked (capability milestones)
- **The current landscape:** classification of today's top-tier / frontier models available in the market right now

## 5. Why Now Is the Time to Learn (~5 min)

- The barrier to entry has effectively disappeared — anyone can start
- You learn faster _with_ AI: working together with it accelerates the learning loop
- (This is the "hype" beat — end it high, then transition into fundamentals)

## 6. Basic Software Architecture (~10 min)

- What is code, what is an application
- The shape of an app: **client → server → database** (how they connect)
- How deployment works — where your app actually lives when it's "live"
- Deliberately stays at the architecture level; **do not go down into code**

## 7. Live Demo (~35–40 min)

- **Idea comes from the audience** — take inspiration directly from the room
- Build it no matter how hard it is; see how far we can go
- **Goal 1:** get _something_ built and **deployed** — shipping is the win
- **Goal 2:** gather feedback from the audience and iterate toward something more complex, as far as time allows

## 8. Closing (~5 min)

- Show the vibe coding skill tiers (beginner → intermediate → advanced)
- Position the workshop: "this course gets you to **intermediate**"
- End on an inspirational note
